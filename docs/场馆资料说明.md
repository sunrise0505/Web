# 场馆资料与演示设置

本轮目录依据山东大学公开的体育馆与风雨操场名称建立。系统是课程项目，没有接入学校正式预约平台。

## 公开资料

- [山东大学体育学院：体育场地收费标准公示](https://www.tyb.sdu.edu.cn/info/1116/6607.htm)：资料列有中心、兴隆山、千佛山校区风雨操场，以及趵突泉、洪家楼校区体育馆。
- [山东大学体育学院：基层教学组织](https://tyb.sdu.edu.cn/zzjg/jcjxzz.htm)：列有相关校区体育馆、风雨操场办公地点，可辅助核对校区归属。
- [山东大学（青岛）：校区简介](https://www.qdxq.sdu.edu.cn/xqgk1/xqjj.htm)：综合体育馆含篮排球馆、健身大厅、游泳馆等运动空间。

## 初始目录

| 校区 | 课程演示预约单元 |
| --- | --- |
| 中心校区 | 体育馆羽毛球区、风雨操场篮球区 |
| 洪家楼校区 | 体育馆羽毛球区 |
| 趵突泉校区 | 体育馆篮球区 |
| 千佛山校区 | 风雨操场篮球区 |
| 兴隆山校区 | 风雨操场篮球区、羽毛球区 |
| 软件园校区 | 羽毛球场，按用户要求沿用中心校区配置 |
| 威海校区 | 体育馆羽毛球区、篮球场、体育中心游泳馆 |
| 青岛校区 | 综合体育馆篮球区、游泳馆、健身大厅 |

场馆名中的“篮球区”“羽毛球区”是为本项目安排的预约单元名称，不是对官方独立场地编号的核验结果。每个单元按一个时段一份团体预约处理；项目容量、开放时间、用途、提前预约天数和签到规则均是课程演示参数，不能作为学校实际预约依据。未核实的门牌、楼层、收费和开放政策不写入目录。

管理员可继续维护八个校区的场馆。预置目录覆盖八个校区，不表示已完整收录山东大学所有体育设施。旧版六条示例场馆及其预约记录保留，不会被此次目录更新覆盖。

新增空库通过初始化程序添加 14 个预约单元；已有本地 demo 库会补齐缺失项，重复启动不会重复添加相同校区与名称的项。学校 MySQL 已于 2026-11-01 按用户要求完成校区迁移与目录补充；旧场馆和预约保留。

威海资料补充：
- [数学与统计学院羽毛球赛事报道](https://math.wh.sdu.edu.cn/info/1087/30133.htm)提供校区体育馆举办羽毛球赛的信息。
- [山东大学（威海）体育中心游泳馆采购资料](https://zbb.wh.sdu.edu.cn/zb/cgxxfwl/7974.chtml)提供游泳馆信息。

软件园羽毛球场及威海篮球场在本项目中作为演示预约区域配置，不宣称核实了官方的独立场地编号、楼层和实际开放政策。软件园的说明、容量、开放时间、配色与中心校区羽毛球区一致，仅名称和位置不同。
