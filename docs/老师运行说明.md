# 老师在其他电脑运行本系统

## 本地演示包

文件：`artifacts/sdu-venue-demo.zip`。请先完整解压到可写的普通文件夹，再运行，不要直接在压缩包内运行。

前提：电脑已安装 Java 21，终端执行 `java -version` 能找到该版本。演示包未附带 Java 安装程序；未安装 Java 时不能直接运行。无需 Node.js、Maven、MySQL，也不依赖学生电脑或学校数据库。

- Windows：双击 `start-windows.bat`。
- Mac：双击 `start-mac.command`，或在该文件夹打开终端，运行 `bash start-mac.command`。
- Linux：在该文件夹运行 `bash start-linux.sh`。

看到启动成功、端口 22222 的日志后，浏览器打开 http://127.0.0.1:22222 。启动窗口须保持开启，关闭窗口或按 Ctrl+C 即停止服务。不是双击 ZIP 或 JAR 就自动显示网页。

账号：admin / Admin123!；student 或 student2 / Student123!。首次运行自动创建独立本地演示数据库、14 个场馆与演示预约；数据保存在解压文件夹的 `data` 子目录，重启后保留。包中不含原开发电脑的历史数据。多日后首次创建的演示记录会变成历史，但仍可新建当天及未来预约。

手动启动的等价命令：

```bash
java -jar java-server-1.0-SNAPSHOT.jar --spring.profiles.active=demo --server.address=127.0.0.1
```

端口被占用时，可在命令后增加 `--server.port=22223`，改为打开 http://127.0.0.1:22223 。请勿同时启动多个实例访问同一份 data 文件库。Mac 启动文件不能双击时优先使用上述终端命令。

## 源码包

`artifacts/campus-venue-source.zip` 用于源码复查或继续开发，不包含依赖和 JAR。直接打开源码目录不会自动运行网站。需按 README 安装 Java 21、Maven 与 Node.js，下载依赖并构建。

## 学校在线验收

按课程要求上传指定名称的 `java-server-1.0-SNAPSHOT.jar`，使用学校分配的在线 MySQL。当前学校第 11 组库已完成校区字段迁移与场馆补充；运行 mysql 模式仍须通过环境变量提供单独交接的数据库密码。演示包中的启动文件显式选择 H2，仅适用于本地演示，不能替代在线验收。

本项目尚未上传学校提交网站。换电脑的验证范围是 Java 21、全新目录、无旧数据和无学校数据库连接下的独立启动与业务流程，不代表已在所有 Windows/Mac 环境逐台测试。
